## V1.0.0 · 2026-11-22

### 新增功能
- 资产查看：填写解包后的 Content 目录，自动列出其中的 uasset / umap / uexp 并统计数量
- LOCRES 查看：选中 .locres 直接查看 key / source / target 三列与条目总数
- Mappings 文件夹：设置中指定一个目录，各面板可快速切换其中的 .usmap
- 路径历史：路径输入框记录用过的路径，点击即可从列表选回
- 状态标识：路径增加「已安装 / 未安装 / 默认」状态点，绿点就绪、红点缺失
- 版本面板：展示当前版本，支持填写 GitHub 仓库检查更新
- DUMP 面板：列出目标进程、可设置注入前等待、注入 DLL 并启动 Dumper
- 主题切换：提供黑 / 白两套主题，即时生效并写入配置

### 完成的工作
- 七个工具模块全部面板化，统一为同一套界面与交互
- 界面统一黑白配色，输入框、下拉、开关、徽标尺寸与描边一致
- 过渡与弹出动画整体重做，切换更顺滑
- 各模块路径与参数独立持久化，支持粘贴路径与手动选择
- 关于页补充功能说明、优点、使用流程与免责声明
