TI 工具箱 · UE4/5 工具箱

        
面向 UE4/UE5 工程的资源与本地化处理工具集。单文件可执行，内置密钥提取、pak 编解码、locres 本地化、文本定位、字体替换与签名绕过能力。


        
功能

        
AES Key 提取pak 解包 / 打包locres 汉化文本定位字体替换绕签名


        
优点

        
    
          
  • 统一入口：密钥、解包、文本、打包、验签在同一进程内完成，免去跨工具链切换
    • 
          
  • 参数可复用：目标目录与密钥按模块独立持久化，exe / pak 路径自动探测
    • 
          
  • 过程可追溯：调用的命令、参数与输出完整落日志，支持复现与审计
    • 
          
  • 可扩展：工具定义与调用命令由 catalog.json 声明，新增工具无需改动主程序
    • 
        


        
新增

        
    
          
  • 资产路径：资产查看内直接填写解包后的 Content 目录，下方列出其中的 uasset / umap / uexp 并给出计数
    • 
          
  • LOCRES 查看：选中 .locres 即可查看 key / source / target 三列与条目总数
    • 
          
  • Mappings 文件夹：设置里指定一个目录，UAssetGUI 与 FModel 面板可快速切换其中的 .usmap（含子目录，最多 3 层）
    • 
          
  • 路径历史：游戏目录 / 资产目录 / 资产路径输入框记录用过的路径，可从下拉中直接选回
    • 
          
  • 界面统一：深浅两套主题均为黑白配色，输入框、下拉、复选框与状态徽标采用同一套尺寸与描边
    • 
          
  • 文案规范：每个功能的标题与说明统一为「做什么 + 关键参数与产物」的表述
    • 
        


        
使用

        
    
          
  • 本地化流程：文本抽取 → 翻译 → locres 重建 → 补丁 pak 打包 → 未签名包加载验证
    • 
          
  • Mod 制作：资源解包核查、贴图与文本替换、重新打包与加载验证
    •
